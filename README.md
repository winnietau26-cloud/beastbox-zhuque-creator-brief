# BEASTBOX ZHUQUE Creator Shooting Brief

English creator shooting brief, including the complete embedded video reference.

The original self-contained HTML is gzip-compressed and split into parts to fit GitHub browser upload limits. No video is trimmed or replaced. `python3 build.py` restores the exact original HTML to `_site/index.html` and verifies its SHA-256 checksum before publishing.

GitHub Pages builds and deploys automatically on changes to `main`.
